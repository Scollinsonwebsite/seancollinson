# Website generation prompt — Sean Collinson, "Reset or Repeat"

Build a single-page, fully responsive author/speaker website for **Sean Collinson** (author, speaker, negotiation expert) promoting his book **"Reset or Repeat — Break the patterns before they break you."** Style: premium dark-luxury editorial, cinematic, confident, warm gold on near-black navy. Use semantic HTML5, CSS custom properties, vanilla JS, no framework. Fully accessible (WCAG AA), mobile-first responsive, fast (lazy-load below-the-fold images, WebP, `font-display: swap`).

## Design tokens
- **Colors:** background `#04060b` → `#080d18` (near-black navy, subtle vertical gradient); card panels `#0a1020` with 1px borders `rgba(122,150,196,.30)`; gold ramp `#f6dc98` (highlight) / `#e0b45a` (base) / `#a8741f` (shadow) as a vertical gradient for gold text and buttons; primary text `#f5f0e6`; secondary text `#b4bccb`; tertiary `#8892a6`. Warm amber glows (`rgba(214,150,70,.28)`) and deep-blue glows are the only accents; no other hues.
- **Typography:** Display/headings **Playfair Display** 700–800 (high-contrast serif; hero title uppercase, tight leading .92); body/UI **Montserrat** 400–600; accent **Great Vibes** script in gold for pull quotes and the hero tagline. Micro-labels: Montserrat 500–600, uppercase, letter-spacing .2–.3em, 9–11px, gold or muted. Hero title ≈ 4.5vw (max 83px); section titles 1.15–1.6rem uppercase with .07em tracking; card titles 1.1–1.65rem serif; body 14–16px / 1.65.
- **Spacing:** 4–8px base; max width 1440px, fluid gutter `clamp(18px, 4.2vw, 64px)`; grid gap `clamp(12px, 1.1vw, 18px)`; section padding 28–48px (compact, magazine-dense rhythm).
- **Shape/depth:** card radius 10px, button radius 6px, small tags 3px; gold hairline dividers; soft gold glow on primary buttons; deep drop-shadow under the book; photos fade into the background with CSS masks (no hard edges).

## Interaction & responsive behavior
- Hover: gold buttons lift 1px and brighten; text links widen the arrow gap; play buttons scale 1.07 with gold ring. Focus-visible: 2px gold outline. Respect `prefers-reduced-motion`.
- Waveform bars fill gold as audio plays; one preview plays at a time; if no audio file is set, show a "coming soon" notice rather than fake playback.
- Breakpoints: ≥1181 full layout; ≤1180 hero drops the script text, feature cards go 2-up (third full width), players scroll horizontally; ≤980 hamburger nav, hero stacks (portrait on top fading into copy, then book centered), credibility strip 2×2, feature cards 1-up, About stacks; ≤560 full-width buttons, pillars stacked, hero title 10.6vw.
